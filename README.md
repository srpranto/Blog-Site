# 🏕️ Bangla Trek — Travel & Adventure Platform

Bangla Trek is an interactive travel and trekking web platform designed for exploring outdoor locations and adventure routes. Built with modular SCSS and clean responsive HTML layout.

## 🛠️ Main Technologies Used

- **Markup:** HTML5
- **Styling & Preprocessing:** SCSS (Sass), CSS3
- **Package Management:** Node.js & npm

---

## ✨ Key Features

- 🗺️ **Destination Explorer:** Interactive UI showcasing trekking routes and outdoor spots.
- 🎨 **Modular SCSS Architecture:** Organized CSS using Sass variables, mixins, and partials.
- 📱 **Mobile-First Responsive Layout:** Renders seamlessly across desktop, tablet, and mobile browsers.

---

## 📦 Dependencies

- **Sass (Syntactically Awesome Style Sheets):** Used for compiling `.scss` files to standard CSS.
